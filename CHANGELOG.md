# Changelog

## [1.13.17] - 2026-11-06

* Автогенерация протокола через LLM: чекбокс «Генерация протокола автоматически» в метаданных (вкладка «Скрам и DeepSeek»), при включении создаётся `protocol.md` (редактируется во встроенном редакторе, Ctrl+M) после транскрибации.
* Промпт для автогенерации протокола берётся из сохранённого файла `deepseek_prompt.*` папки записи (он содержит промпт, указанный при создании записи, контекст, глоссарий, предыдущий протокол и стенограмму). Если файла нет — используется шаблон из Настройки → Скрам.
* Новый пункт «Промпт для генерации summary» в Настройках → «Промпты и имена» — промпт для генерации summary теперь настраивается, хардкод убран (fallback: «Промпт по умолчанию»).
* Кнопка «Утвердить протокол» в окне «Записи» — запускает generation summary для автогенерированного протокола.
* Кнопка «Повторить автогенерацию протокола» — для записи, где автогенерация не удалась.
