# Changelog

## [1.13.19] - 2026-11-10

* Генерация поручений теперь двухэтапная (вместо поиска подстроки-маркера «ПОРУЧЕНИЯ» в протоколе):
  * Этап 1 — сбор поручений: модель читает полный протокол/стенограмму и возвращает только фрагменты текста про поручения (сужает контекст);
  * Этап 2 — генерация JSON: модель превращает сужённый текст в JSON с поручениями.
* Оба шаблона промптов редактируются в Настройки → Скрам: «Этап 1 — сбор поручений (сужение контекста)» и «Этап 2 — генерация JSON».
* Новый ключ конфига `scrum.action_items_collect_prompt_template` (этап 1); существующий `scrum.action_items_prompt_template` — теперь этап 2. Старые конфиги работают без изменений (подмешивается дефолт этапа 1).
* Для отладки сырые ответы обоих этапов сохраняются в папке записи: `action_items_response_collect_raw.txt` (этап 1) и `action_items_response_raw.txt` (этап 2).

## [1.13.18] - 2026-11-10

* Библиотека промптов (Настройки → «Промпты и имена»): у каждого промпта можно задать собственный «Промпт для summary». Если для записи выбран промпт из библиотеки, summary (и из протокола, и из стенограммы) формируется по его привязанному промпту; если его нет — используется глобальный «Промпт для генерации summary», как раньше.
* Создание/редактирование промптов — через окно (кнопки «Добавить»/«Изменить» или двойной клик по строке): название, многострочный текст промпта и промпт для summary. Таблица промптов в настройках — только для просмотра.
* Кнопка «Сохранить как новый промпт…» в окне метаданных тоже открывает это окно (текст пре-заполнен).
* Назад-совместимость: старые конфиги и записи без привязанного summary работают без изменений.

## [1.13.17] - 2026-11-06

* Автогенерация протокола через LLM: чекбокс «Генерация протокола автоматически» в метаданных (вкладка «Скрам и DeepSeek»), при включении создаётся `protocol.md` (редактируется во встроенном редакторе, Ctrl+M) после транскрибации.
* Промпт для автогенерации протокола берётся из сохранённого файла `deepseek_prompt.*` папки записи (он содержит промпт, указанный при создании записи, контекст, глоссарий, предыдущий протокол и стенограмму). Если файла нет — используется шаблон из Настройки → Скрам.
* Новый пункт «Промпт для генерации summary» в Настройках → «Промпты и имена» — промпт для генерации summary теперь настраивается, хардкод убран (fallback: «Промпт по умолчанию»).
* Кнопка «Утвердить протокол» в окне «Записи» — запускает generation summary для автогенерированного протокола.
* Кнопка «Повторить автогенерацию протокола» — для записи, где автогенерация не удалась.
